# 怎么用：管理台与网页版

部署完之后的日常操作。装机步骤见 [deploy.md](deploy.md)，出问题见 [faq.md](faq.md)。

## 管理台

`http://<NAS>:8964/admin`，五个页签，**每个都有自己的地址**，可以收藏或发给另一个管理员，刷新和前进后退都成立。

| 页签 | 地址 | 干什么 |
|---|---|---|
| 用户 | `/admin/users` | 建账号。**服务端不自动建号**，宾客的名字只能在这里出现 |
| 授权 | `/admin/grants` | 选一个人，勾出他能看到的照片。**整体替换，不是追加** |
| 配置 | `/admin/config` | 识别阈值、入库闸门、会话时长、素材挂载点 |
| 媒体 | `/admin/photos` | 库里有什么、各自配了哪段视频 |
| 批量 | `/admin/batch` | Excel 模板下载 / 导入 / 导出 |

> 管理台与网页版**同源、共用同一条会话**，点开不用再登一次。在管理台里点「登出」会把扫描页那边一起作废 —— 想换账号才用它。

### 素材挂载点（配置页底部）

「照片和视频从哪儿找」。除了 compose 里的 `PHOTOAR_ROOTS`（会列出来，只读），还能在这儿加，**改完立刻生效，不用重启**：

| 类型 | 填什么 | 行为 |
|---|---|---|
| 本机绝对路径 | 容器内的目录，如 `/media/photos` | 直接读，**不拷贝** |
| WebDAV | 完整地址 + 可选用户名/口令 | 添加时先下载到落地目录 |

WebDAV 地址：群晖是 `https://<host>:5006/`，Nextcloud 是 `https://<host>/remote.php/dav/files/<用户名>/`。填错时会区分「不是 WebDAV 端点」「凭证不对」「连不上」—— 三者下一步动作不同。

SMB / NFS 没有单独做客户端（要引第三方依赖，而这个项目对依赖的姿态是能用标准库做完就不引 —— 见 [decisions.md 的「素材挂载点：本机绝对路径 + WebDAV」](decisions.md#26-素材挂载点本机绝对路径--webdav)）。在宿主机 `mount` 好再挂进容器，那样它就是个普通路径，用「本机绝对路径」。

> ⚠️ 挂载点的口令**明文存在库里**（`data/catalog.db`）。没有 KMS 时加密只是把明文换成「明文 + 一层仪式」，真正的边界是 `data/` 的文件权限。给 WebDAV 用一个只读、只能看照片目录的账号。
>
> ⚠️ 加「本机绝对路径」会**扩大服务端愿意读的范围**。这在管理员权限之内（他本来就能改配置），但每次变动都会在日志里记一行。

### 媒体页

顶部「添加照片」：挑一张图 → 挑配它的视频（可跳过）→ 入库并建映射。照片已入库的话不会只报「已存在」，而是告诉你那是哪一张、现在配的是哪段，并问要不要换。

四个视图，不是详略之分，是四个不同的问题：

| 视图 | 回答什么 |
|---|---|
| 按照片 | 这张配了吗 |
| 按视频 | 这段视频影响谁（一段迎宾视频往往配给很多张，改它之前要知道牵动哪几张） |
| 全部素材 | 服务端上这个文件是谁、谁在用、能不能删 |
| 重复 | 哪些东西是多余的、会互相拖累识别 |

**按照片**每行多一个「编辑」，弹出的对话框分两截：上半截标题 / 打印宽度 / 贴合模式（跟随默认、裁切填满 fill、完整留边 fit），改完点「保存」才生效；下半截「换参考图」「换视频」「解除视频」「删除照片」点了立刻生效，不用点保存 —— 两截分开是因为「我点了换视频、但没点保存，到底换了没有」不该是一个问题。解除关联只清 photo 表那两列，**视频文件不删**。

**全部素材**是落地目录里的每个文件 ∪ 库里记着的每个素材，一行一个路径 —— 删了照片留下的素材记录、转码产物、同一张图传了两份、入库被拒的那张，在这一页之前哪一处都看不到，自然也删不掉、改不了。顶上按状态筛：全部 / 未入库 / 已映射 / 重复 / 被拒 / 孤儿。动作按状态给：未入库的图片能「入库」，视频能「配给照片…」；已映射的视频只能「从 N 张照片解除并删除」（先从那几张上解绑，只属于它们的转码产物一起清掉）；**已映射的图片不给删**，要删只能先删那张照片本身 —— 删照片会连带丢掉它的全部授权，这里不会代劳（见 [faq.md「管理台删不掉某个文件」](faq.md#管理台删不掉某个文件)）；孤儿只能删记录。

**重复**把三种「多余」放一页：同内容多份（同一份字节传了两次）、入库时被判重复的那张（拒绝记录，可以拿它「用它替换『X』的参考图」）、库内近重复（点「扫描」才跑，几十秒到分钟级，不随刷新自动重扫）。

列表**下面**还有一段「传上来但还没入库的文件」：手机传上来的先落地再入库，中间断了（超时、判近重复、人退出了）就躺在那儿。图片可以在那儿直接入库，视频可以挑照片配上去。

> 媒体页在你**切回这个标签页**时自动重取，所以手机上加完照片、转回电脑看一眼就是新的。其它几页刻意不自动刷 —— 那上面有你改了没保存的东西。

#### 从手机相册传，不只是从 NAS 挑

所有「挑一个文件」的地方（添加照片、换参考图、换视频、配给照片…）第一项永远是「从手机/本机选一个文件上传」——手机上点了直接弹相册，电脑上是普通的选文件，传完接着原来的流程走，不用先把文件弄到 NAS 上。

只想先把素材放到服务端、还没想好配给哪张照片：去「全部素材」页右上角点「从手机上传素材…」（可以多选，只传不入库），传完在「未入库」筛选里再入库或配视频。

### 批量页

流程是「下模板 → 填 → 导入（只预览）→ 执行」。一行 = 一个用户 + 一张照片 + 一段视频 + 一次授权，填几列就做几件事。

- 路径填的是**容器内**路径（和 `PHOTOAR_ROOTS` 一致），不是你电脑上的。这是导入失败最常见的原因，所以预览阶段就会逐行指出不在白名单、不存在、类型填反的路径。
- 选完文件**只是预览**，一行都还没写库。确认后点执行，逐行做，每行成败单独显示。
- 逐行执行是**浏览器**在做的，**执行期间别关页面**。关了就停在半路 —— 改完出错的几行再导一遍是安全的（重复的用户和照片不会建两遍）。
- `.xlsx` 和 `.csv` 都收。Excel「另存为 CSV」默认写 GBK，也认。
- 「用户」那份导出的表头与模板一致，可以导出 → 改 → 导回来。

## 网页版

### 宾客和管理员看到的不一样

| | 宾客（viewer） | 管理员（admin） |
|---|---|---|
| 底栏 | 扫一扫 / 设置 | 照片 / 素材 / 管理 / 设置 |
| 首页 | 整页一颗「扫一扫」，下面一行「你有 N 张照片可扫」 | 照片库，扫一扫是底栏中间那颗圆 |

名字必须是管理台里建过的。**宾客留空口令**，管理员必填。

给宾客说一句「打开链接，输你的名字，口令不用填」就够了。他说扫了没反应，先看首页那行提示：显示「管理员还没有把照片授权给你」就是授权没做，跟他手机无关。

管理员的「管理」页里有管理台入口、识别历史、本机缓存。

### 「素材」页：手机相册 → NAS

婚礼当天刚拍的东西在手机里，而管理台跑在 NAS 上看不到。挑一张照片 + 配它的视频，点一次「传上去并建立映射」就完事。

上传时会问照片印出来有多宽（七个预设）。**留「不知道」完全没问题** —— 网页版按四个角贴，不看物理尺寸，这个数只是记进库里。

**上传历史**列出这台手机传过的每一组，每条都能：

- **换照片** —— photoId 不变，所以授权和配的视频都留着（换成更清楚的扫描件时用）
- **换视频 / 配视频** —— 当时忘了配就在这儿补
- **试播** —— 全屏放一遍确认配对没错，不开相机

历史只记这台手机传的（换个浏览器就看不到）。全库的映射在管理台「媒体」页。

> 换照片要重算特征，几十秒是正常的。被拒时服务端会说清原因，并且明确告诉你**原来那张没有被换掉**。

**上传是先查后传的**：页面先在本地算哈希问服务端一次（几百字节、几十毫秒）。内容已经有了就**整个跳过上传**，不会让你等着传完 20MB 才被告知「已存在」。

传到重复的照片时服务端会拦（这是对的），但**不是死胡同** —— 页面会查出那张已有照片，按情况给出唯一可做的那件事：

| 库里那张 | 你这次挑了视频 | 给你什么 |
|---|---|---|
| 已有别的视频 | 是 | 「换成新的」（说清旧的不再关联） |
| 还没配视频 | 是 | 「配上」（不覆盖任何东西） |
| 配的就是这段 | 是 | 「已经是你要的样子了」 |
| 任意 | 否 | 说清现状；没配视频时提醒你去配 |

> 一张照片只能配**一段**视频，一段视频可以配给**多张**照片。所以「视频重复」从来不是问题，「照片重复」只能去改已有的那一张。

**入库要多久**：一张 10MP 手机照片约 3.5 秒（开发机；N5095 上 3～4 倍），视频转码另算。嫌慢就去配置页调**入库时自匹配分的计算分辨率**：默认 1280，调 960 快 4 倍，代价是去重判定略保守。

### 「本机缓存」：出门前先把能扫的都存到手机里

登录后网页会在后台把你能扫的那些视频（连同缩略图）悄悄存到这个浏览器里，扫到时直接从本机播、不用等网络。媒体库页每张卡片右下角一个「缓存」按钮，四种状态：

| 按钮上写什么 | 意思 | 点了做什么 |
|---|---|---|
| 缓存 | 还没存 | 把这一组（原图 + 视频）存到本机 |
| 下载 42% | 正在存 | 不可点，进度就在按钮上 |
| 自动缓存 | 后台顺手存下的（登录后预取、或看过之后自动存下），空间紧张时可能被新入库的挤掉 | 固定它（不重下，只是打上「别自动删」的记号） |
| 已缓存 | 你点过「缓存」或点过「自动缓存」固定下来的 —— 不会被自动清掉 | 从本机移除 |
| 无视频 | 这张没配视频 | 不可点 |

顶上「本机缓存」木牌一行「已缓存 N / M 组 · 占用 X」，加一个「全部缓存」（把还没固定的都固定下来；离开这一页也会接着下）和一个「管理缓存」→ 单独的「本机缓存」页：能看到识别库、预取的媒体、每一组的固定 / 自动标签与大小、浏览器给这个站点的存储配额，以及「清空自动缓存」（只清没固定、也没在下的）和「清空全部」（视频 / 原图 / 缩略图 / 单个媒体来源的本机文件与固定记录全清，正在播的那一段不受影响）两个按钮。

点开宾客自己那一张照片，也有一块同样的「本机缓存」木牌（原图 + 视频一组）；试播页、宾客页、扫描页三处播放器都会**边下边播边报进度**：「已下载 3.2 / 8.1 MB」，下完变「已存到本机，下次秒开」——存下来的正是缓存的那一份，之后再扫到这张不会重下。

「本机缓存」和下面「存到手机」是两回事：前者存进这个**浏览器**（没网也能在网页里看、扫到秒开，但相册里看不到），后者交给浏览器的下载器、落进手机的下载目录。

### 设置页「高级设置」：默认声音、更快的地址、单独换一段视频的来源

设置页「账号」下面有一块收起的「高级设置」，点「展开高级设置」摊开，三块：

- **视频默认有声音**：「开」/「关」，默认「开」。浏览器不允许有声自动播放时会先静音播，点一下屏幕任意处（或点视频上的喇叭 / 「开声音」按钮）就有声音——宾客页、试播页点在视频本身上不算数（原生的静音键就在视频的控件里，点它只会切换这一次的静音，不会触发解锁），要点视频外面的地方；这个开关只改默认偏好，页面上点「静音」只影响正在看的这一段。
- **媒体数据源**：填一个更快的地址（比如家里 NAS 的局域网地址），之后视频 / 原图的下载改走它，页面和相机仍走当前地址。「启用」/「停用」两个开关，「测试」按钮会连一次并顺手测速（局域网、默认地址各测 2MB），连不上会给出照着做的提示（见 [faq.md](faq.md#设了局域网数据源还是慢--测试不通过)）。这条路**只加速、不能成为新的故障点**：连不上会自动退回默认地址续传，不影响播放。
- **单个媒体的来源**：给某一张的视频单独换一个来源 —— 挑一张照片，「直链」（要对方允许跨域）或「本机文件」（从手机相册选，会复制一份进浏览器存储；Edge 安卓版只能播分片 MP4，也就是用下面「存视频」存下来的那种文件）。

### 取景器底下那一行

**非调试模式下基本是空的**，这是有意的：宾客要的答案只有一句「我该怎么做才能看到视频」，而库里几张、多少 fps 一个都不回答，挤在一起还会把真正有用的那半句（「这张照片还没配视频」）盖掉。

打开调试模式（设置 → 关于 → **连按版本号 7 下**）那行才变成完整技术读数，屏幕上还会出现一块滚动日志：抽帧、识别耗时、内点数、四角坐标、视频 `readyState` 全在里面，截个图就够排查。

零散补几组走「素材」页，批量走管理台「批量」页 —— 区别只是素材在哪：素材页从**手机相册**取，批量页处理**已经在 NAS 上**的文件。
